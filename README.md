# SchweißPilot

Version **1.0.0** – Foundation

Offlinefähiger Schweißparameter-Assistent als Progressive Web App.

## Enthalten

- Rechner für empfohlene Startwerte
- Live-Nahtfeedback per Slider
- Slider-Korrektur über den gesamten Bereich von -10 bis +10
- Startwerte in drei Spalten: A links, V mittig, Vorschub m/min rechts
- sichtbare Versionsanzeige
- modulare Struktur
- PWA-Manifest
- Service Worker für Offlinebetrieb
- Lexikon mit Skizzen/Bildern
- Schweißpositionsskizzen
- Fase- und Mehrlagenskizzen
- Fehlerdiagnose
- MIG/MAG, MIG Aluminium, WIG, Elektrode/MMA, Fülldraht selbstschützend und Plasmaschneiden

## Nicht enthalten

- Fülldraht gasgeschützt
- Herstellerdatenbanken
- KI-Unterstützung
- Projektverwaltung

Diese Funktionen sind für spätere Versionen vorgesehen.
